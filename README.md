# Tic Tac Toe

A simple two-player command-line Tic Tac Toe game built with C while learning the language.

## Features

- Two-player gameplay
- Input validation
- Win and draw detection

## Build

Requires a C compiler and CMake 4.0 or later.

```sh
cmake -S . -B build
cmake --build build
```

Run the generated `TicTacToe` executable from the build directory.
